# Student Tracker Pro 🎓

Современное веб-приложение для учёта посещаемости с геймификацией и аналитикой.

## 🚀 Возможности

- **Тепловая карта года** (GitHub-style) с интерактивной сеткой
- **Быстрая отметка** посещений одним кликом
- **Статистика посещаемости** с расчётом допуска к сессии (>80%)
- **Дисциплины** с цветовой индикацией и статистикой
- **Геймификация**: стрики, достижения, цели
- **Экспорт данных**: CSV, PDF-отчёты, JSON-бэкапы
- **Адаптивный дизайн**: мобильная и десктопная версии
- **Синхронизация с Supabase** для хранения данных в облаке

## 🛠 Технологический стек

- **Frontend**: React 18 + TypeScript + Vite
- **Стилизация**: Tailwind CSS v4
- **Анимации**: Framer Motion
- **Состояние**: Zustand
- **База данных**: Supabase (PostgreSQL)
- **Аутентификация**: Supabase Auth
- **Иконки**: Lucide React
- **Эффекты**: Canvas Confetti

## 📦 Установка

### 1. Клонирование и установка зависимостей

```bash
git clone <repository-url>
cd student-tracker-pro
npm install
```

### 2. Настройка Supabase

#### Создайте проект в Supabase

1. Перейдите на [supabase.com](https://supabase.com) и создайте аккаунт
2. Создайте новый проект
3. Дождитесь завершения развёртывания

#### Примените миграцию базы данных

1. Откройте SQL Editor в Supabase Dashboard
2. Скопируйте содержимое файла `supabase/migrations/001_initial_schema.sql`
3. Выполните SQL-запрос

#### Настройте аутентификацию

1. Перейдите в Authentication → Providers
2. Убедитесь, что Email provider включён
3. Опционально: отключите подтверждение email для упрощения тестирования:
   - Authentication → Providers → Email
   - Отключите "Confirm email"

#### Получите API ключи

1. Перейдите в Settings → API
2. Скопируйте:
   - **Project URL** (например, `https://abc123.supabase.co`)
   - **anon public key** (начинается с `eyJ...`)

### 3. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```bash
cp .env.example .env
```

Заполните `.env`:

```env
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key-here
```

### 4. Запуск приложения

```bash
npm run dev
```

Приложение будет доступно по адресу: http://localhost:3000

## 🗄 Структура базы данных

### Таблицы

- **profiles** - профили пользователей (расширение auth.users)
- **subjects** - дисциплины
- **day_records** - записи посещаемости
- **user_achievements** - достижения пользователей
- **user_goals** - цели пользователей

### Row Level Security (RLS)

Все таблицы защищены RLS-политиками. Пользователи могут видеть и изменять только свои данные.

### Автоматизация

- При регистрации автоматически создаётся профиль и инициализируются достижения
- Автоматическое обновление `updated_at` при изменении записей

## 🔐 Аутентификация

Приложение использует Supabase Auth с Email/Password провайдером.

### Процесс входа

1. Пользователь вводит email и пароль
2. Supabase проверяет учётные данные
3. При успехе создаётся сессия и JWT токен
4. Данные пользователя загружаются из Supabase в локальный Zustand store

### Синхронизация данных

- Локальный Zustand store используется для быстрого доступа
- Все изменения синхронизируются с Supabase в реальном времени
- При входе данные загружаются из Supabase
- При выходе локальные данные очищаются

## 📊 Расчёт посещаемости

```typescript
// Формула расчёта рейтинга посещаемости
rating = (attended + excused * 0.75 + sick * 0.5) / total * 100

// Допуск к сессии
admissible = rating >= 80%
```

**Статусы:**
- `ATTENDED` - присутствовал (100%)
- `EXCUSED` - уважительная причина (75%)
- `SICK` - болезнь (50%)
- `SKIPPED` - прогул (0%)
- `HOLIDAY` - праздник/отмена (не учитывается)

## 🎮 Геймификация

### Достижения

- 🏆 **Идеальная неделя** - 7 дней подряд без прогулов
- 💪 **Железная воля** - 30 дней без прогулов
- ⏰ **Пунктуальность** - 50 посещённых дней
- 💯 **Сотня** - 100 посещённых дней
- 🏃 **Марафонец** - 60 дней стрик
- 👑 **Чемпион** - 95% посещаемости
- 🌅 **Ранняя пташка** - первый день семестра

### Цели

Пользователи могут создавать персональные цели:
- Указать целевой процент посещаемости
- Выбрать период (неделя/месяц/семестр)
- Отслеживать прогресс в реальном времени

## 🚢 Деплой

### Vercel (рекомендуется)

1. Подключите репозиторий к Vercel
2. Добавьте переменные окружения:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
3. Vercel автоматически определит Vite и задеплоит

### Netlify

1. Подключите репозиторий к Netlify
2. Build command: `npm run build`
3. Publish directory: `dist`
4. Добавьте переменные окружения

### Docker

```dockerfile
FROM node:20-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build
FROM nginx:alpine
COPY --from=0 /app/dist /usr/share/nginx/html
```
